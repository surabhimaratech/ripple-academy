# Ripple Academy heroine — original Milestone 2.3 production record

Current animation/occlusion work is documented in [Milestone 2.3.1](HEROINE-ACTIVITY-EXPANSION.md). The original approved PNGs listed below remain unchanged.

The user-approved canonical design sheet is preserved unmodified at `public/art/references/ripple-academy-heroine-design-sheet.png`. An additional user-supplied sprite-sheet presentation discovered in the project is preserved as `public/art/references/ripple-academy-heroine-animation-reference.png` for future animation guidance. Neither complete reference sheet is loaded by the game. The source copies at the project root are untouched.

## Identity and palette

Young adult university scholar, with warm brown eyes, long wavy dark brown hair and a purple ribbon. Royal purple tailored jacket, antique gold embroidered cuffs/trim, ivory blouse and ribbon tie, charcoal pleated skirt, dark tights, lace-up leather boots, golden dolphin brooch and crossbody satchel. The portrait and game poses share this identity. No permanent character name, needs, mythology or storyline is added.

`public/art/heroine/palette.json` documents the principal palette roles. It guides new art; it does not recolor the approved/generated paintings automatically.

## Assets and renderer

New isolated artwork was generated using the built-in OpenAI ImageGen tool, using the approved design sheet as the identity reference. No paid runtime service, external AI integration, stock art or new dependency is used. The portrait is separate from three transparent atlases. Original rasters retain their alpha and are checked in under `public/art/heroine/`.

- `portrait.png`: 1254 × 1254, chest-up portrait; used in courtyard, RPG HUD and scholar profile in Keepsakes.
- `locomotion.png`: 1254 × 1254, 4 × 4 cells. Rows down/right/up/left; columns idle/blink/stride A/stride B. Back-view alternate is a still hair/ribbon variation.
- `activities.png`: 1448 × 1086, 4 × 3 cells. Seated book/page turn, typing pair, notebook-writing pair, provisional distance-observing pose, window pose, rest, shelf reach, standing book and celebration. The provisional observing cell is deliberately unused; telescope art is supplied separately.
- `telescope.png`: 1536 × 1024, dedicated two-frame side-on eyepiece pose. Uses the room's telescope, not a second baked-in instrument.
- `animations.json`: actual runtime manifest, source grids, named frame locations, target heights, common canvas/foot anchor and playback sequences. `palette.json`: palette reference.

`src/heroine/atlas.ts` partitions fractional source cells without dropping columns, locates the largest connected alpha silhouette to reject generator specks, retains a small detail margin, and uniformly fits it into a 96 × 144 transparent canvas with foot anchor (48,136). It never redraws the heroine. Nearest-neighbor scaling preserves source pixels. Normalized canvases are cached, and Phaser textures are created once per game. Changing a pose requires only a manifest entry/asset replacement. Existing scene depth sorting uses the navigation foot position, while render-only seated/desk/eyepiece offsets align her with existing furniture.

`src/heroine/animation.ts` is a pure pose selector. `ScholarView` renders those frames; `ScholarBehavior` still owns activities, routes, manual override and celebration resumption. No renderer imports currency or persistence rules. Reduced motion freezes walk/typing/writing/page-turn/eyepiece playback, blinking and breathing, while keeping the appropriate still pose. Hidden-tab pausing stays in the existing room lifecycle.

## Complete vs limited vs missing

| Feature | Delivered | Limitation / follow-up art |
|---|---|---|
| Portrait and identity | Complete canonical-derived original portrait | A final artist review can refine exact embroidery/face consistency; no generic portrait fallback |
| Four-direction idle/blink/walking | Four authored orientations, idle/blink and two stride poses per direction; 4-beat contact/stride playback | Short cycle, not a fully hand-authored eight-frame gait; extra in-betweens would improve fluidity |
| Idle breathing | Tiny bottom-anchored 0.2% breathing with blink | Rendered breathing, no separately painted chest/hair deformation frames |
| Seated reading | Book + page-turn poses, occasional page-turn timing | One authored three-quarter orientation; no directional seated turnarounds |
| Typing / notebook writing | Two-frame hand/quill variations, scene furniture stays separate | Limited rear-three-quarter orientation; desk/chair hand-and-seat contact remains provisional and needs room-matched artist frames; no independent arm rig or fully bespoke chair transitions |
| Telescope | Dedicated two-frame eye/hand adjustment; separate from instrument | Limited side view; final artist-authored eye/eyepiece and hand contact can be refined per telescope |
| Window / rest | Authored still poses with subtle breathing | No multi-frame hair drift or stretch sequence; resting uses the same supplied seated rest pose |
| Shelf browsing / standing book / celebration | Authored reach, held book and quiet smile poses | Each is one pose; exact facing variants remain future art |
| Arrival/departure | Existing FSM timing and smooth render-offset settling preserved | Fully drawn sit-down/stand-up transitions are not provided |

There are **no geometric character placeholders in the running application**. The unused observing cell is provisional, not presented as completed telescope art. Missing refinements are reported here rather than imitated with the old block sprite. The old procedural scholar and old SVG portrait were removed.

## Replacing and extending artwork

1. Supply isolated RGBA artwork with transparent backgrounds, orthographic camera, no labels/grid lines or baked-in room furniture. Use the canonical outfit/proportions. Keep feet fully visible and each silhouette inside its cell.
2. Use a consistent equal-cell grid or supply a new atlas/manifest entry. Standing frame target height is 112 pixels; seated frames 88. All output frames are 96 × 144 with common foot origin. Preserve apparent head/body proportions across poses.
3. Update `animations.json` atlas sources, rows/columns, named frames and clips. File dimensions may be non-divisible by grid size; the importer partitions them safely. Do not add padding containing a second character, chair or captions.
4. Extend the pure selector for new named poses; retain still-frame selection for reduced motion. Outfit customization should replace texture sets, not change collision or currency logic.
5. Verify every frame on a dark and light background, boot alignment, silhouette separation, same character scale and color identity. Inspect each room's furniture contacts, occlusion and portrait crops. Run all tests and the build.

## Explicit activity mirroring

Starting Coding/Interview preparation selects the Study laptop. Reading selects a reading activity in the configured room. Astronomy/Physics use the Observatory telescope and existing chart/book variations. The new default Journaling category uses the Study notebook; writing/journaling intent in another configured room selects its writing desk/chart activity. Existing custom category room mappings are honored; saved catalogs are not overwritten. Existing pause, finish, manual override and reward rules remain unchanged. Autonomous art/activities never award XP or gold.
